# PERSONEL — Günlük Kullanım Kılavuzu (V1)

## Amaç
Personel kendi vardiyasını görür ve gerektiğinde konum bazlı **request** açar.

## Günlük Akış
1) **Benim Servisim** ekranına gir
2) Aktif/planlı vardiyanı gör
3) Gerekirse **Talep Oluştur**
   - Konumunu al veya manuel lat/lng gir
   - Request oluştur

## İpuçları
- Request’ler Room tarafında “stop-suggestions” üzerinden durak planına eklenir.
